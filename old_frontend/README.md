# Old Frontend - Siddhartha's Portfolio Website

This folder contains the original Jekyll-based portfolio website that was moved here to make room for a new site implementation.

## Structure

```
old_frontend/
├── includes/          # Jekyll includes (head, header, footer)
├── layouts/           # Jekyll layouts (home, project, article, template, default)
├── data/              # Jekyll data files (intro, work, skills, contacts, achievements)
├── posts/             # All blog posts and project pages
├── assets/            # All static assets (CSS, images, PDFs, SVGs)
├── app.js             # JavaScript functionality
├── index.md           # Home page content
├── 404.html          # Error page
└── favicon.ico       # Site favicon
```

## Key Components

### Includes
- **head.html**: HTML head section with meta tags and resource links
- **header.html**: Navigation bar with responsive mobile menu
- **footer.html**: Site footer with contact links and copyright

### Layouts
- **default.html**: Base HTML structure
- **template.html**: Wrapper with header and footer
- **home.html**: Main portfolio page layout
- **project.html**: Individual project page template
- **article.html**: Blog post template

### Data Files
- **intro.yml**: Personal introduction paragraphs
- **work.yml**: Work experience entries
- **skills.yml**: Technical skills by category
- **achievements.yml**: Professional achievements
- **contacts.yml**: Social media and contact links

### Posts
- **Project Posts**: 13 project pages (professional and self-projects)
- **Article Posts**: 3 blog posts (devlogs and technical articles)

### Assets
- **CSS**: Custom styles with responsive design
- **Images**: Project screenshots, profile pictures, banners
- **SVGs**: Social media icons
- **PDFs**: Resume and other documents

## Technology Stack
- **Static Site Generator**: Jekyll 4.2.0
- **Theme**: Minima (customized)
- **Styling**: Custom CSS with responsive design
- **JavaScript**: Vanilla JS for interactive features
- **Deployment**: GitHub Pages

## Features
- Responsive design with mobile-first approach
- Dark theme with blue accent colors
- Project portfolio with professional and self-projects
- Blog section with technical articles
- Work experience timeline
- Skills and achievements display
- Contact integration with social media
- Smart navbar with scroll behavior
- Custom 404 error page

## Content Organization
- **Professional Projects**: Work done for companies/organizations
- **Self Projects**: Personal game development projects
- **Blog Posts**: Technical articles and development logs
- **Work Experience**: Chronological professional history
- **Skills**: Organized technical competencies
- **Achievements**: Professional accolades and recognition

This structure served as a comprehensive portfolio website showcasing Siddhartha's game development and graphics programming expertise.
